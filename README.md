## ✨ Introduction

♻️ **Trash Trade Marketplace** is a simple web platform built using HTML, CSS, and JavaScript.  
It enables users to sell their recyclable waste by creating a clean and intuitive interface.  
The system bridges local waste providers like households and small vendors with companies that need reusable materials.

## ✅ Our Goals

- Reduce landfill waste by promoting recycling and reuse.  
- Provide fair pricing to local waste contributors.  
- Supply clean, sorted, and reusable materials to companies.

## 🛠 Features

- ✅ User-friendly Interface  
- 📄 Paper, Metal, Plastic waste listing  
- 🏢 Simple navigation (Home, How It Works, Our Mission, Contact)  
- 📷 Hero image for attractive landing experience
